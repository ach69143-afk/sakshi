### Quick Launch

1. **Backend**:
   ```bash
   cd sakshi/backend
   .\venv\Scripts\Activate.ps1
   uvicorn main:app --reload --port 8000
   ```

2. **Frontend**:
   ```bash
   cd sakshi/frontend
   npm run dev
   ```

Open `http://localhost:5173/` in your browser.
